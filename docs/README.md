# Материалы Для Сдачи

- GitHub-репозиторий: https://github.com/rvaleev2016-eng/conveyor-defect-detection
- Главная задача ClearML: https://app.clear.ml/projects/1b01d7ca2ca741fb881df31ee748a1e6/experiments/0db5742cb68f4c46919dcb64fed478e7/output/log

## Что находится в папке

- `report.pdf` — итоговый PDF-отчёт для сдачи.
- `report_source.md` — текстовая основа отчёта.
- `task_journal.md` — журнал выполненной работы по основным этапам.
- `clearml_report_outline.md` — готовая структура финального отчёта в ClearML Reports.
- `clearml_report_export.md` — короткая инструкция по экспорту правильного `report.pdf` из ClearML.
- `presentation/conveyor_defect_detection_presentation.pptx` — готовая презентация по проекту.
- `assets/` — ключевые графики и визуалы для отчёта.
